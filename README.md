# Chatgpt

This project contains a simple example website introducing the basics of quantum computing. The main site files live in the [`website/`](website/) directory:

- `index.html` – the landing page with a short explanation of the site's intent.
- `style.css` – minimal styling for the page.
- `app.js` – placeholder JavaScript for future demonstrations.

Open `website/index.html` in a browser to see the example.
