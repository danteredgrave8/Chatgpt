# Contributing Guidelines

Thank you for considering contributing to this project!

## Issues

* Search the existing issues before opening a new one.
* Provide a clear description of the problem and steps to reproduce.

## Pull Requests

* Fork the repository and create your branch from `main`.
* Ensure your code follows the existing style and includes tests when possible.
* Describe your changes in the pull request description.
* Link any relevant issues in the pull request.
